## 🇷🇺 Русский

**Монополия** — классическая настольная игра, реализованная в браузере.

### Возможности
- 🎮 Локальная игра (2-4 игрока)
- 🤖 Игра с ботами
- 🌐 Онлайн-мультиплеер
- 💾 Сохранение игры
- 🏆 10 достижений
- ⚙️ Гибкие настройки

### Технологии
| Компонент | Стек |
|-----------|------|
| Клиент | HTML5, CSS3, JavaScript |
| Сервер | Node.js, Express |
| БД | SQLite (sql.js) |
| Сеть | WebSocket |
| Авторизация | JWT + bcrypt |

### Установка

npm install
npm start
