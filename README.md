## 🇷🇺 Русский

**Монополия** — классическая настольная игра, реализованная в браузере.

### Возможности
- 🎮 Локальная игра (2-4 игрока)
- 🤖 Игра с ботами
- 🌐 Онлайн-мультиплеер
- 💾 Сохранение игры
- 🏆 10 достижений
- ⚙️ Гибкие настройки

### Технологии
| Компонент | Стек |
|-----------|------|
| Клиент | HTML5, CSS3, JavaScript |
| Сервер | Node.js, Express |
| БД | SQLite (sql.js) |
| Сеть | WebSocket |
| Авторизация | JWT + bcrypt |

### Установка
```bash
npm install

npm start

Открыть http://localhost:3000
```

Правила игры
Классические правила Монополии: покупка недвижимости, строительство домов и отелей, залог, торговля, аукционы, карты «Шанс» и «Казна», тюрьма.

## 🇬🇧 English

**Monopoly** — classic board game implemented in the browser.

### Features
- 🎮 Local multiplayer (2-4 players)
- 🤖 AI bots
- 🌐 Online multiplayer
- 💾 Game saves
- 🏆 10 achievements
- ⚙️ Customizable settings

### Tech Stack
| Component | Stack |
|-----------|-------|
| Client | HTML5, CSS3, JavaScript |
| Server | Node.js, Express |
| Database | SQLite (sql.js) |
| Network | WebSocket |
| Auth | JWT + bcrypt |

### Setup
```bash
npm install

npm start

Open http://localhost:3000
```
